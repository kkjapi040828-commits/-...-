DLsite 도우미 설치 안내

아래에서 PC인지 모바일인지 골라 주세요 · 약 3분

Tampermonkey(탬퍼몽키) 설치하기

크롬에서 Tampermonkey를 검색해서 크롬 웹 스토어 페이지를 열어요. 파란 [Chrome에 추가] 버튼을 누르고, 팝업이 뜨면 [확장 프로그램 추가]를 눌러요.

💡 이미 설치돼 있으면 사진처럼 [Chrome에서 삭제]라고 보여요. 그땐 이 단계는 끝난 거예요.

개발자 모드 켜기

크롬 주소창에 chrome://extensions 라고 치고 엔터. 오른쪽 위의 개발자 모드 스위치를 켜요(파란색이 되면 켜진 거예요).

💡 이걸 안 켜면 스크립트가 안 돌아갈 수 있어요.

Tampermonkey 메뉴 열기

크롬 오른쪽 위 퍼즐 모양(확장 프로그램) 버튼을 누르고, Tampermonkey 아이콘을 눌러요. 메뉴가 뜨면 [도구]를 눌러요.

💡 아이콘이 안 보이면 퍼즐 버튼 안에서 핀 모양을 눌러 고정해요.

스크립트 파일 가져오기

새 탭이 열리면 [가져오기] 칸의 [파일 선택]을 눌러요. 내가 보낸 dlsitehelper.user.js 파일을 골라요. 설치 확인 화면이 뜨면 [설치]를 눌러요.

💡 파일은 미리 바탕화면 같은 곳에 저장해 두면 찾기 쉬워요.

잘 깔렸는지 확인

[설치된 유저 스크립트] 탭에 DLsite ... 가 보이고, 스위치가 초록색이면 성공이에요. 이제 DLsite 사이트를 열어 보세요.

💡 안 보이면 DLsite 페이지를 새로고침(F5) 해 보세요.

Firefox(파이어폭스) 앱 설치

플레이 스토어에서 Firefox를 설치하고 열어요. 폰에서는 크롬에 Tampermonkey를 못 깔아서 Firefox를 써요.

💡 DLsite는 앞으로 Firefox에서 열어야 해요.

메뉴에서 확장 기능 열기

오른쪽 위 ⋮ 버튼을 누르고, 메뉴에서 [확장 기능]을 눌러요.

확장 기능 관리

목록 맨 아래의 [확장 기능 관리]를 눌러요.

확장 기능 더 찾기

맨 아래 [확장 기능 더 찾기] 버튼을 눌러요.

Tampermonkey 추가

검색창에 Tampermonkey를 찾아서 들어간 뒤 [Firefox에 추가](또는 추가) 버튼을 눌러요.

💡 이미 설치돼 있으면 사진처럼 [제거]라고 보여요. 그땐 끝난 거예요.
